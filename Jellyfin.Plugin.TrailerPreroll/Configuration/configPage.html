Cache

How often the plugin swaps out the cached trailers for a fresh random set. The trailers live in two auto-created libraries ("Trailer Preroll (Library)" and "Trailer Preroll (Upcoming)"). To hide them, use Dashboard → Users → your user → untick those libraries (do NOT disable the library, which removes the items).
Rolling rotation: once a trailer has played this many times, it's retired and one fresh trailer is downloaded to replace it (a gentle trickle, easier on YouTube than big rotations). 0 = off. Default 5.
Manually fetch/refresh the trailer set now (runs in the background; may take a few minutes).
Re-lists the already-downloaded trailers as proper "Trailer" items instead of generic home videos. This re-scans the two trailer libraries (it does NOT re-download anything — the files stay put) and runs in the background.

Advanced

A gap longer than this between episodes starts a new "session" for the first-episode-only TV mode. Default 180.
How many library-film trailers to keep cached for variety. Larger = more variety and more disk. Default 60. (Ignored if "Keep a trailer for every film" is on.)
How many upcoming trailers to keep cached. Default 12.
Instead of a bounded rotating pool, gradually download and permanently keep a trailer for every film in your library. Great variety, but can use a lot of disk on big libraries.
Max trailers to download each background cycle, so the pool fills gradually instead of all at once (gentler on YouTube). 0 = no limit. Default 10.
Trailers are streamed from a small local cache (yt-dlp + ffmpeg). Oldest are deleted once the cache exceeds this size. Default 2048 (2 GB).
Quality cap for cached trailers (e.g. 720 or 1080). Lower = smaller files. Default 720.
Leave blank to use yt-dlp(.exe) from the server data folder or system PATH.
yt-dlp extraction client(s) used to get past YouTube bot checks (e.g. "android" or "android,ios"). Blank = yt-dlp default.
Path to a cookies.txt exported from a browser logged into YouTube. Strongly improves reliability when YouTube blocks downloads with "Sign in to confirm you're not a bot".

Per-User Overrides

By default every user gets the global settings above. Enable an override for a specific user to give them different trailer selection settings (for example, one user gets any trailer while another only gets unwatched-movie trailers). Download, cache and pool settings are always shared — overrides only change which and how many of the already-downloaded trailers each user sees.
