Rotation

How often the plugin re-picks the cached set. Actual downloading runs on the "Cache trailer prerolls" scheduled task (Dashboard → Scheduled Tasks), where you can set the time it runs. The trailers live in two auto-created libraries ("Trailer Preroll (Library)" and "Trailer Preroll (Upcoming)").
Once a trailer has played this many times it's retired and one fresh trailer is downloaded to replace it. 0 = off. Default 5.

Pool & Downloads

Instead of a bounded rotating pool, gradually download and permanently keep a trailer for every film in your library. Great variety, but can use a lot of disk.

Per-User Overrides

By default every user gets the global settings. Enable an override for a specific user to give them different trailer selection (for example, one user gets any trailer while another only gets unwatched-movie trailers). Download, cache and pool settings are always shared — overrides only change which and how many trailers each user sees.
